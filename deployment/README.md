# Накат базы данных


В данном модуле расположен docker-compose файл для удобного и быстрого деплоя базы данных. 

В модуле расположены две папки:
1. prod 
2. test

Отличие **prod** от **test** заключается в сохранении данных бд после удаления/остановки контейнера, логированием, healcheck-ом
и файлом .env, в котором лежат основные настройки бд. 
Переменные в файле **/prod/.env** необходимо переопределить перед запуском контейнера!!! (docker файле для теста переменные
необходимо править прямо в файле).


## Как запускать

1. Зайдите в одну из папок /prod или /test и введите команду: `docker-compose up -d`
2. В случае необходимости поменяйте конф. данные в .env (не забудьте добавить его в .gitignore)
3. Запустите bash с помощью команды: `bash generate_property.sh` (если поменяли конф.)
4. После этого перейдите к другим действиям описанным в главной README.md

## Отладка

1. Для отладки можете либо ознакомиться с логами `docker logs postgres`
2. Либо зайдите в сам контейнер: узнайте id контейнера `docker ps -a` и введите команду `docker exec -it {id} bash`
3. Дальше можете зайти в psql - `psql -U smart_banking` и ознакомиться с БД подробнее.
