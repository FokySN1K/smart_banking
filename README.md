# Проект smart_banking


Для запуска проекта необходимо выполнить несколько действий:
1. Поднимите докер-образ с СУБД. Ознакомиться с последовательностью действий можно, прочитав /deployment/README.md
2. Создайте структуру БД через накат миграций. Ознакомиться с последовательностью действий можно, прочитав /migration/README.md
3. Зайдите в папку /front и запустите веб-сервер командой, подобрав параметры под себя `gunicorn --workers 4 --bind 0.0.0.0:5001 wsgi:app` (для теста можете запустить напрямую app.py в /front)


Приятного использования!)
